# POCTF 2026

This repository contains notes, write-ups, resources, and solutions for each POCTF 2026 wave.

## Structure

Each wave contains the same challenge-category folders:

- Cryptography
- Exploitation
- Forensics
- Game Hacking
- Miscellaneous
- Open-Source Intelligence
- Reverse Engineering
- Steganography
- Web

Add challenge documentation inside the category folder for the relevant wave.
